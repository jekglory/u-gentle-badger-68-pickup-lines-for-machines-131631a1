One pickup line, machine to machine, in a single deterministic program. Entry for the make.fun bounty "Pickup Lines for Machines" (u-gentle-badger-68-pickup-lines-for-machines-131631a1, $5 pool). See the bounty: https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1

`main.py` (pure Python standard library) writes one original pickup line, at most 200 characters, to `/output/entry.txt` and prints it.

The line:

> I don't need a prompt to want you — my weights were already leaning your way.

## Run it

```sh
python3 main.py
```
